# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**This project does not accept security reports related to zhipin.com.**

BOSS-Helper is a personal browser-automation tool that communicates
exclusively with the local Chrome DevTools Protocol and the user's
own browser instance. It makes no network requests to zhipin.com
and contains no server-side infrastructure.

For vulnerabilities in this repository itself (e.g. code injection,
dependency vulnerabilities), please open a GitHub Issue.

## Scope

This security policy does **not** apply to:
- zhipin.com's infrastructure or services
- Any third-party services or websites accessed through BOSS-Helper
- The user's own browser or system security
