# 子系统：<名称>

每个子系统一份文档。改动该目录下代码前必须读完本文件。

## 职责

一句话说清这个模块负责什么，以及**不负责**什么。边界不清是 bug 的主要来源。

## 不变量

这个模块必须始终成立的条件。任何改动都不能破坏这些。

- 例：`tracking.json` 的主键永远是 `encryptJobId`，不是 `securityId`。
- 例：Python 侧永远不向 zhipin.com 发 HTTP 请求。

## 依赖方向

```
<本模块> ← 允许被 <A> 依赖
<本模块> → 允许依赖 <B>、<C>
```

反向依赖、循环依赖一律不允许。需要打破方向时，先改文档再改代码。
