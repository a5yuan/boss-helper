# 统计页的图表手写 SVG，不引图表库

投递统计页要柱状图、折线图、热力图三种图。全部手写 SVG，不引入 Chart.js / ECharts / uPlot。理由：三种图形状都很基础（热力图本质是带颜色的表格），而这个页面只读、不需要缩放和 tooltip 交互，图表库带来的主要是用不上的功能，代价是 60–300 KB 体积和一个新的构建依赖。

## Considered Options

- **ECharts**：三种图都现成，但 ~300 KB gzip，且热力图仍需单独配置坐标系。
- **Chart.js**：~60 KB，柱状和折线够用，热力图需要额外插件或手写。
- **uPlot**：~40 KB，只擅长折线，另外两种还是得手写，等于混着来。

## Consequences

图表代码约 300–400 行，由本项目维护。以后要做交互（悬浮提示、区间缩放）时，成本会高于直接用库；那时可以重新评估，但需要把三个图一起迁移，混用两套渲染会不一致。
