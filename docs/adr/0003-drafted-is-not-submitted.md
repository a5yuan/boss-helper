# `drafted` 与 `submitted` 在统计中分开计数

BOSS 直聘走 `prefill_chat`（只填草稿不发送），智联走 `apply_then_chat`（真实投递）。两者的记录都进事件流，但 `drafted` 不计入「已投递」总数，只在图表里单独显示。理由：草稿对方收不到，把两种状态合成一个「投递数」会让统计页给出错误的判断依据——数字涨了但实际没有一家公司收到简历。

## Consequences

顶部大数字里的「总投递数」只统计 `submitted`；`drafted` 单独一个数字或在柱状图里用不同颜色堆叠。看板使用者需要知道这两种颜色的含义，所以页面上要有图例说明，不能只靠颜色区分。
